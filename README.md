# Yandex_Afisha_Project

## 📌 Описание
Анализ поведения пользователей Яндекс Афиши в летне-осенний период 2024 года для выявления причин изменения динамики заказов и среднего чека, а также сравнения мобильных и десктоп-пользователей.

## 📊 Данные
- Заказы, события, курс тенге  
- Объединение, очистка, пересчёт в рубли  
- Создание новых признаков: месяц, сезон, цена за билет

## 🔍 EDA
- Динамика заказов по месяцам, сравнение сезонов (лето vs осень) по типам событий, устройствам, возрастным рейтингам  
- Ежедневная и недельная активность осенью (DAU, заказы на пользователя, средний чек)  
- Топ-регионы и партнёры

## 🧪 Гипотезы (осень)
1. Мобильные пользователи совершают больше заказов на человека, чем десктопные  
2. Время между заказами у мобильных пользователей больше, чем у десктопных

## 📈 Результаты
- Инсайты по сезонным изменениям, структуре чека и активности  
- Статистическая проверка гипотез  
- Рекомендации для продукта:
  - Оптимизация мобильного интерфейса  
  - Фокус на популярные осенние события  
  - Работа с ключевыми партнёрами и регионами
